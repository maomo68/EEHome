How to use it

  1. Load an image. Click "Load base image" and pick a JPG or PNG (1024x1024 works best). Images are resized to a power of two, up to 2048x2048, as Second Life needs.
  2. Check the two previews. The sphere shows the PBR result with lighting. The flat plane shows how the texture repeats without lighting, so you can spot visible seams. Use "SL tiling" to test different repeats.
  3. Tune the material. Roughness: 0 is shiny, 1 is matte. Metallic: 0 is non-metal, 1 is full metal. Normal scale sets the strength of the relief. Emissive makes the material glow.
  4. Set the transparency. Keep OPAQUE for solid surfaces. Use MASK for leaves, fences and cut-outs (adjust "Alpha cutoff"), and BLEND for semi-transparent surfaces.
  5. Name it and export. Type a material name and click "Export .GLTF for SL". The file downloads with all the maps already inside.
  6. Upload it to Second Life. In the viewer, open Build → Upload → Material and choose the .gltf file. Then apply the material to an object face from the Texture tab.
